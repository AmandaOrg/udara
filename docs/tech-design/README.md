# Tech designs

Engineer-readable **how** for a feature. Architecture, types, files, env, and tests. Product rules stay in [../specs/](../specs/README.md).

## Rules

- Open with links to the spec and initiative plan.
- Name modules, services, and invariants. Prefer paths over prose.
- Record test commands (targeted Jest, golden ids, e2e names).
- Update in the same PR as the code.
